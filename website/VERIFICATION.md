## 固定移动性能环境

`npm run measure:perf` 使用安装的 Chrome `154.0.8037.98`，390×844、DPR 1、触控、
CPU 4 倍减速、150ms 延迟、下载 1.6Mbps／上传 0.75Mbps、关闭缓存。
本地端口 4322 对 HTML／CSS／JS／SVG 使用 gzip；WOFF2／WebP 使用原编码。
每个语言三个独立冷启动样本，未同时运行其他浏览器测试。

| 页面   | LCP 三次（ms）   | CLS 三次     |
| ------ | ---------------- | ------------ |
| `/`    | 1224／1032／1036 | 均为 0.00148 |
| `/en/` | 992／916／908    | 均为 0.04353 |

六个样本均满足本轮目标 LCP ≤2.5s、CLS ≤0.1；均保持二维且未请求 3D。
这是固定模拟环境中的本地冷启动测量，不代表公网托管、真实手机或所有网络。

`2026-10-11T13:09:38.003Z`；中文构建 HTML SHA-256 为

## 实际 GPU 渲染测量

同一 Chrome、1440×900、DPR 1，headless 模式加 `--enable-gpu`。
实际渲染器：`ANGLE (AMD, AMD Radeon(TM) Graphics (0x0000164E) Direct3D11 vs_5_0 ps_5_0, D3D11)`。
每章采集 180 个 requestAnimationFrame 间隔，五章均保持高画质 3D。

| 章节     | 平均间隔（ms） | 平均循环 FPS | p95 间隔（ms） |
| -------- | -------------: | -----------: | -------------: |
| 开场     |           8.37 |       119.44 |          12.60 |
| 现场计分 |           9.79 |       102.17 |          12.60 |
| 亲手体验 |           8.09 |       123.54 |          12.50 |
| 赛后复盘 |          11.18 |        89.45 |          12.60 |
| 下载     |           7.33 |       136.45 |          20.90 |

平均渲染循环均高于 60 FPS；下载章 p95 超过 16.7ms，不能宣称每帧均达目标。
该测量使用实际硬件 GPU，包含渲染负载，但衡量的是 headless 浏览器的 rAF 节奏，
没有使用 GPU timer query，也没有测量物理屏幕呈现帧率。物理显示器与真实手机的
体验仍可在上线前补充检查；远端性能、CI 和 Vercel 预览均未作为本轮通过项。
