## 实现

- 章节标题按实际容器安排字号与断行，正文16px，辅助文字14px以上。计分标题使用容器尺寸，避免把整句挤成多行碎片
- 统一圆角、按钮状态、焦点和间距。普通信息面桌面32px、手机24px，操作条适当收紧。保留烟灰、米白、橙色和蓝红身份
- 阅读渐变贴合卡片内部，减少嵌套框。独立标题、首屏底部和页脚使用柔和的局部遮光；页脚没有新增玻璃底座
- 首次计分邀请保留首按钮边线、指示点和箭头，取消整张截图与其他按钮的暗化。播放、暂停、取消、重播和减少动态效果行为保留
- 二维码、大图和下载入口保持清晰，校验码与升级说明继续折叠。正文新分段通过 `white-space: pre-line` 呈现
- 最低画质 CSS 降级移出减少透明度媒体查询。背景滤镜的标准声明置于厂商前缀之后，避免构建优化只保留 Chrome／Firefox 不支持的前缀
- 回归中定位并修复 WebKit 的滚动写入误取消：程序写入后的实际读回允许一次不超过3px的原生修正，只在当前切章动画内有效。预览与最终落位仍使用2px边界，较大未知跳转和明确的用户操作继续接管；24px意图阈值与1.05秒过渡不变

完整文案、humanizer说明及逐字段中英前后对照见 [组件双语文案稿](component-copy-2026-11-01.md)。366个字符串路径保持不变，两个隐私对象源码逐字保留。没有改写版本、比分、FG／FT分母、备份恢复边界或发行来源。

预览为 `http://127.0.0.1:4321/`，审阅页为 `http://127.0.0.1:4323/`。证据放在忽略目录 `website/output/component-polish-20261101/`；审阅页提供两语七章的原始前后截图、适配实拍和可读的双语文案稿。生成器在同目录，截图来自真实浏览器渲染。

本轮重建中文字体子集和同源场景展示图，由现有资产流程更新 SHA-256 与来源绑定。实际 App 截图只沿用已有干净展示副本。

最终验证结果见本地 `verification.md`。检查包含格式、类型、全量单测、生产构建和资源预算，以及相关三浏览器回归。失败与修正前的日志原样保留，不能把中间失败当作最终构建通过。

最终组件与输入专项57项中56项通过。Chrome与Firefox各19项通过，WebKit通过18项，连续原生滚轮仍有1项间歇性失败。全量单测274项通过、1项平台跳过；类型、格式及资源预算通过。完整滚动回归的其他失败样本仍保留于原始日志，不以这轮专项替代全部平台验收。

对比度采样使用生产 WebGL 静态阅读画面：字体与布局保持不变，临时隐藏字形后，在文字实际行矩形中采样背景，按原前景色计算保守的最低比值。正文／小字以4.5:1、大字以3:1为目标；这项检查不证明任意过渡帧或全部设备均通过。

## 保留的限制

此前 AMD／NVIDIA 的 GPU 性能失败和 Windows WebKit 的原生滚轮投递限制仍单独保留。本轮没有把它们改记为通过，也没有据静态截图宣称帧率达标。本轮发现的写入误取消另有失败记录、修复与回归，不与此前限制混为一项。WebKit 自动化不等于实体 Safari；本轮没有新增真实 Safari 证据。

没有输入事件且恰好落在同一写入回执3px范围内的外部脚本跳转，无法仅凭位置与浏览器修正完全区分。回执只消费一次，取消、刷新和落位时清空，避免累计放宽边界。

改动保持本地，未提交、推送、部署或更新长期预览分支。本记录属于组件维护说明，不启动项目收尾或 AOCI 维护。
