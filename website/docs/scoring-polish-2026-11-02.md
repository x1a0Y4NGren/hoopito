## 局部操作提示

`scoring-feedback.ts`继续只处理HTML/SVG展示，不写App记录，不自动选择功能。

| 项目     | 契约                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 首次邀请 | 第一项短线800ms提亮，不缩放圆点、不播放箭头；一次页面生命周期最多一次                |
| 桌面触发 | 章节处于真实阅读范围、滚动控制器idle、第一项至少60%可见且无暂停原因，在下一帧触发    |
| 手机触发 | 章节与阅读视口相交、第一项至少60%可见且无暂停原因                                    |
| 点击演示 | 总长1.94秒，目标外遮暗不超过0.18，静态细描边表示选择                                 |
| 点击圈   | 原图坐标半径18到52，400ms淡出；左右计分分别在240ms与860ms开始，其余目标240ms开始     |
| 清理     | 完成、离章、切换或重播先清除临时遮暗与点击圈，圈半径回18，保留所选项、细描边和说明   |
| 暂停     | 后台与大图暂停原因共同控制局部时钟，全部释放后恢复；系统减少动态效果直接显示静态选择 |

邀请资格在同帧组件姿态更新后检查，离章取消不影响投篮演示或球馆的状态所有权。
主章节动画仍从真实滚动位置推导；局部点击提示继续使用原有可暂停GSAP时间线，未新增主场景播放时钟。
