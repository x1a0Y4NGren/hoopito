## 逐项视觉检查

已查看原尺寸图、近邻放大图、暖白／近黑／纯白底及六张组合 PNG，检查透明边缘、裁切、文字和间距：

| 项目             | 结果与使用限制                                                                       |
| ---------------- | ------------------------------------------------------------------------------------ |
| 32px 透明图      | 主体约 20×20px，眼睛和橙色轮廓可辨，笑和篮球纹路软化；不用于要求完整细节的小型展示。 |
| 64px 透明图      | 主体约 38～40px，表情及球纹清楚，未见明显异色边。                                    |
| 英文，浅底／深底 | 文字完整、橙色句点保留，使用对应背景时对比清楚。                                     |
| 中文，浅底／深底 | 两字完整，图标和文字未相互遮挡。                                                     |
| 双语，浅底／深底 | 英文粗窄体与中文常规体保持现有字体，间距一致、无裁切。                               |
| 单色与紧裁版     | 深底负空间可辨；紧裁不丢原像素，放置时另留至少主体宽度 10% 的空白。                  |
