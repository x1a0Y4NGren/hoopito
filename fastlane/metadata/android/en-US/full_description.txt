Hoopito is an offline app for one-on-one basketball. Start quickly, record on court, understand your results, and build a player history.

Match, History, and Players tabs retain your browsing state. Start with temporary names, existing profiles, or a new player. Reuse the last setup, swap sides, and review the rules. Choose free scoring or a target from 1 to 999. At the target, confirm the finish or continue with the actual score; the timer still applies. Mainly keep score or record every shot in the same landscape workspace, with points, misses, fouls, locations, undo, save status and retry feedback. Open the quick guide from the scoring menu when needed.

Continuous matches keep the same pair across games, even when red and blue are swapped. Each game starts fresh; adjust its rules and timer before playing. Wins follow the saved results, draws are listed separately, and abandoned games do not count as wins or losses. Continue from Home and revisit each game from History. Finish or abandon the current game before closing a series. Reopen it from History when no other series or match is active. Each game counts once toward player statistics.

Confirm the final score and recording scope, then open a result summary, full replay, or share report. Link a temporary participant to a profile while keeping their match name, or start a fresh rematch. Player careers and comparisons show recorded evidence: field-goal and free-throw percentages use separate denominators, and incomplete or zero-attempt samples show no percentage. Growth charts, two-match comparisons, and 7/30/90-day windows help you see changes over time.

Export complete JSON, readable CSV, or a replay image. Replacement and rollback require a verified private safety copy; active matches block replacement. The two latest valid copies are normally retained. Import and export limits are 32 MiB, 100,000 rows per table and 200,000 rows in total. Private copies, CSV and images do not replace an external JSON backup.

Android software updates can be checked manually in Settings. Startup checks are on by default and can be turned off. Checks use HTTPS to the official website, with GitHub as a fallback, without uploading matches, players, settings or device identifiers. These services receive connection information such as your IP address. Download only when you choose, then confirm installation in Android; updates are never forced or installed silently. Active matches block installation.

All records stay on the device by default. There is no account, cloud sync, advertising, analytics, tracking, or personal-data upload. Optional automatic backup is off by default and writes only to a user-approved folder. The official Hoopito project remains permanently free and open source under the MIT License.

The black, white, and orange cyclops basketball icon has a silent launch animation. Skip it or use reduced/disabled motion. Simplified Chinese and English, system/light/dark themes, system font settings, and adaptive layouts are available.

Android is the current release platform; iOS is not formally released. v2.0.0/v2.0.1 support an in-place update to v2.1.0. Back up first; existing matches are not automatically grouped. v2.0.1 users must install the new version manually once to get the updater. v2.1.0 uses schema 4 and JSON format 2, imports older supported HoopTrace/Hoopito backups, and includes series in complete backups. New schema 4 backups require v2.1.0 or later; do not downgrade and reuse the upgraded database.

Historical v1 uses a different certificate and cannot update in place. Export a complete JSON backup and verify it is saved outside the app, then uninstall v1, install this version and restore. Uninstalling deletes private app data and internal safety copies.
