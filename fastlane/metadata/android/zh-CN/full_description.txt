Hoopito · 球豆 是一款离线单挑篮球应用，帮助你快速开赛、现场记录、看懂赛果并积累球员成长。

比赛、历史、球员三个入口保留浏览状态。开赛前可用临时名称、已有档案或新建球员，复用上场配置、交换双方并查看规则。可选自由计分，或设置 1～999 的目标分；达到目标后按真实比分确认结束或继续，计时到期仍然生效。选择主要记分或记录每次出手，两者共用横屏计分页，保留得分、未中、犯规、落点和撤回，并提供保存状态与重试反馈；需要时可从计分菜单打开快速上手说明。

连续对局固定同一对球员，交换红蓝方后仍正确累计各自胜场。每场从零开始，可先调整下一场规则和计时。胜场按已保存赛果计算，平局单列，放弃不算胜负。首页可继续未结束的对局，历史可进入每场复盘；每场只计入球员统计一次。完成或明确放弃当前比赛后可结束整组；没有其他未结束组或活动比赛时，可从历史重新打开。

结束时确认比分和记录范围，再查看总结、完整复盘或分享报告；可为临时参与者关联档案，保留当场姓名，或创建一场全新的再赛。生涯与比较如实表达已记录样本：投篮和罚球命中率分别计算，不完整或零出手时不显示可信百分比。成长曲线、两场对局及 7/30/90 天时间窗比较帮助你查看变化。

支持完整 JSON、可读 CSV 和复盘图片导出。替换与回退前必须保存经校验的内部安全副本；活动比赛期间禁止替换，正常保留最近两份有效副本。导出和导入同为 32 MiB、单表 100,000 行、总计 200,000 行上限。私有副本、CSV 和图片不能代替 App 外的完整 JSON 备份。

Android 可在设置中手动检查软件更新，启动检查默认开启，可关闭。检查通过 HTTPS 访问官网，失败时尝试 GitHub，不上传比赛、球员、设置或设备标识；分发服务会接收 IP 地址等连接信息。由你选择下载，并在 Android 系统安装器中确认，没有静默安装或强制更新，活动比赛期间不能安装。

记录默认留在本机，无账号、云同步、广告、分析、追踪或个人数据上传。自动备份默认关闭，仅写入用户授权目录。官方项目永久免费、开源，采用 MIT License。

采用黑白橙独眼球怪图标与静音启动动画；可跳过，支持减少或关闭动画。提供简体中文和英文、系统/浅色/深色主题、系统字体设置及自适应布局。

Android 为当前发行平台，iOS 尚未正式发行。v2.0.0／v2.0.1 可覆盖升级至 v2.1.0，请先备份；已有比赛不会自动归组。v2.0.1 用户需先手动安装一次新版，才能使用更新器。v2.1.0 使用 schema 4、JSON 格式 2，可导入兼容的旧 HoopTrace／Hoopito 备份，完整备份同时保留连续对局关系。新 schema 4 备份需要 v2.1.0 或更高版本恢复，请勿降级后继续使用已升级的数据库。

历史 v1 与 v2 正式证书不同，不能覆盖安装；如需保留旧记录，先导出完整 JSON 并确认已保存到 App 外，再卸载旧版、安装新版并恢复。卸载会删除应用私有数据与内部安全副本。
