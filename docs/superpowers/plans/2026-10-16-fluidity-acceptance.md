# Hoopito · 球豆：流畅度优化与整页体验验收

**Goal:** 保留已经批准的视觉和交互，通过可信的双 GPU 测量与完整用户路径找出并修复实际卡顿、突变和流程缺陷。

**Architecture:** 延续 Astro、GSAP、单一背景 Three.js 场景与现有状态机；测量工具独立于产品运行时。环境有效性、渲染提交、GPU 成本与画面呈现分别报告，不混用证据。

**Spec:** 本对话用户于 2026-10-16 明确要求实施的同名五部分计划。

## 约束

- 当前网站分支实施，保留之前未提交内容；仅本地审阅，不提交、推送、部署、更新 Issue、AOCI 或 HANDOFF。
- 保留夜场、玫瑰金、聚光箭头、连续镜头、540° 卡牌、6:6→8:6、1.20s / 0.35s / 0.58s 投篮及暂停重置行为。

- 所有 GPU、浏览器与 Android 验收串行；纯源码分析与测量工具开发可并行。
