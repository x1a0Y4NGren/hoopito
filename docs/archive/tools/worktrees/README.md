# 旧工作树脚本

这两个文件是首发阶段的历史快照，**不作为现行可执行工具**：

- [setup-worktrees.ps1](setup-worktrees.ps1)：原位置为 `scripts/setup-worktrees.ps1`，按当时的任务波次和分支名创建工作树。
- [test-setup-worktrees.ps1](test-setup-worktrees.ps1)：原位置为 `scripts/test-setup-worktrees.ps1`，检查上述脚本的旧版预览输出。

脚本原文及其测试一同保留。它们依赖原目录位置推断仓库根目录，归档后不能直接按旧说明运行；本轮没有将旧波次工具改造成当前工具，也没有执行创建工作树的操作。

当时的命令与背景见[历史执行顺序](../../../branch-execution-order.md)。当前工作树和分支约定以[贡献指南](../../../../CONTRIBUTING.md)为准。来源与摘要见[归档清单](../../manifest.json)。
