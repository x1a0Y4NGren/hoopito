# Hoopito · 球豆 v2.1.1

Android `2.1.1+7`，数据库 schema 4，JSON 格式 2。

## 中文

### 快速上手

- 跟着提示试一遍赛前设置、记分、撤销、记录落点和结束比赛。首次邀请可跳过，也可从「设置 → 快速上手」随时重练。
- 每次练习都是独立的临时比赛，练习记录不进入正式历史、球员统计或备份。从进行中的比赛进入时，先确认暂停原比赛，返回后由你决定何时继续。
- 自动更新提醒会等到首次练习邀请处理完毕，并在练习期间延后显示。

### 升级与备份

官方 v2.0.0、v2.0.1 和 v2.1.0 可覆盖安装，保留本地数据。升级前请将完整 JSON 备份保存到 App 外并确认可读取。v2.1.0 已使用 schema 4，本版无需再次迁移。v2.0.x 的旧数据库仍会自动迁移至 schema 4，旧版无法读取迁移后的数据库或 schema 4 备份。历史 v1 使用不同证书，须先确认已保存完整备份，再卸载旧版、安装新版并恢复。

v2.0.1 及更早版本需要手动安装新版。v2.1.0 的应用内检查优先采用官网的有效版本信息，官网信息未同步时可能暂时看不到新版提示。可从 GitHub 对应版本的 Release 手动下载安装。

## English

### Learn the basics

- Follow the prompts to set up a game, score, undo, mark a shot location and finish. You can skip the first invitation or return anytime in Settings → Learn the basics.
- Each practice game is temporary. Practice records stay out of match history, player stats and backups. If a game is in progress, confirm that you want to pause it before entering practice. You can resume it yourself when you return.
- Automatic update reminders wait until you respond to the first practice invitation and leave practice.

### Upgrading and backups

You can install over official v2.0.0, v2.0.1 or v2.1.0 and keep your local data. First save a complete JSON backup outside the app and verify that you can read it. v2.1.0 already uses schema 4 and needs no further migration. Older v2.0.x databases still migrate automatically to schema 4. Older apps cannot read the migrated database or restore schema 4 backups. Historical v1 installs use a different certificate. Verify your external backup before uninstalling v1, installing the new version and restoring.

Install this version manually if you are on v2.0.1 or earlier. The v2.1.0 updater uses valid website version information first, so it may not show the new version until the website is updated. You can download and install the APK from the matching GitHub Release.
