## 本次范围与兼容性

固定两人的连续对局支持交换红蓝、逐场设置、胜场与平局汇总、场间继续、收局、重新打开以及逐场赛果和复盘。胜场来自已完赛或归档比赛，放弃不计胜负，每场只计入球员生涯一次。普通单场继续独立使用，旧比赛不会自动归组。

本次正式版本也包含此前合入 `main`、尚未随 v2.0.1 公开的 Android 应用内更新、自由／目标计分确认和中英文文案整理。启动检查默认开启、可关闭，网络请求不上传比赛、球员、设置或设备标识；下载及系统安装均由用户选择，活动比赛期间不能安装。完整行为见[双语发行说明](v2.1.0-release-notes.md)和[隐私说明](../../PRIVACY.md)。

本地 schema 2／3 数据库自动迁移至 schema 4，JSON 支持格式/schema 组合 `1/2`、`2/3`、`2/4`。新备份含连续对局及场次关联，旧 App 无法导入 schema 4 备份或读取升级后的数据库；不能降级后继续使用该数据库。v2.0.0／v2.0.1 可同证覆盖安装，升级前应在 App 外保存完整 JSON。历史 v1 证书不同，仍须先导出、确认收到完整备份，再卸载安装并恢复。
