所有 **120 次**原始记录和八组失败均保留。最终四组共 **40／40 standard**，没有 skip／mesh fallback；2597 个 presented 帧合并 build／raster p95 为 **2.948／11.064ms**。仍有 40 个 build、32 个 raster 单帧超过 16.7ms，最大分别为 49.189／36.608ms；验收通过的是已批准的 p95 门槛，没有宣称每帧都达标。total p95 16.777ms 含流水线等待，不作为原有 build／raster 工作预算的替代指标。

前三组同 boot `0ffb14b4-28f5-4663-b953-405a55249228`；复建为 `3942236c-2314-4e02-87ed-2ca024c72331`，无 quick-boot／快照恢复。前三组宿主经过时间与 guest uptime 差异约 0.008／0.017／0.019 秒，epoch 差值符合整秒精度；未修改任何时钟。独立冷重启再次通过，说明这套配置可重复取得预算内结果。

批次波动也照实报告：前三组 raster p95 范围 1.996ms、相对均值 17.899%；没有事后选定“稳定性通过”阈值。中位数为 2.609／2.771／2.530ms，各组尾部均留有预算余量。ASG B／C 的相对差异为 38.584%，Qt GL 三组为 12.142%；变异更小并不自动意味着预算通过。

这些结果支持模拟器宿主合成路径是此前超预算的重要影响因素，不能据此给应用代码宣称优化百分比，也不能直接推断真实手机帧率。没有证据要求继续修改已审核动作来通过这次验收。

## 复建与采集

保留的专用 AVD 在验收后停止，数据未清除。只启动这台专用设备时，使用下面的固定参数；先确认端口没有被其他设备占用，不得对 `5554` 或 `5556` 执行停止／安装／用户操作。

```powershell
$env:ANDROID_AVD_HOME = 'D:/Android/Avd'
$env:ANDROID_USER_HOME = 'D:/Android/UserHome'
# 使用 Start-Process -WindowStyle Hidden，并将 stdout/stderr 写到新的证据目录。
# 现有 AVD 的 config.ini 已固定 hw.gltransport=asg 与上述尺寸。
& 'D:/Android/Sdk/emulator/emulator.exe' `
  -avd HoopTrace_V2_Stable_API36 -port 5562 -gpu host -memory 4096 -cores 4 `
  -no-snapshot -qt-hide-window -no-audio -no-boot-anim `
  -camera-back none -camera-front none `
  -feature '-AsyncComposeSupport,VulkanNativeSwapchain'
```

启动后检查实际日志、boot、API、user10 身份与安装 APK hash，保存当前 guest 设置及 QEMU 优先级再准备屏幕／离线状态。采集前连续三次只读利用率窗口满足 host CPU≤35%、guest CPU≤20%、GPU≤20%；最长等待 60 秒。这是控制外部负载的诊断条件，不改变发行帧预算，不通过丢弃一次启动来达成。

```powershell
python tool/release/measure_entry_startup.py `
  --adb D:/Android/Sdk/platform-tools/adb.exe --serial emulator-5562 --user 10 `
  --runs 10 --require-standard --enforce-budget `
  --apk D:/DevCache/HoopTraceV2Artifacts/home-startup-20261005/hooptrace-2.0.0+4-996146f-profile.apk `
  --source-commit 996146ff5c57efd5c4920dbb5e2955413af33af2 --output <新的仓库外目录>
```

[比较工具](../../tool/release/compare_entry_startup_runs.py)从每个原始 run JSON 重算全部帧，核验同源码／同 APK／设备／预算／次数、完整 presented 和独立冷进程。缺失、降级、跳过或 legacy 样本会拒绝比较；失败和 partial 原始文件继续保留。每个输入记录 SHA-256。预算结果和相对波动分别报告，可选波动限制仅为诊断，不是新增发行门槛。boot、GPU、传输与负载连续性由旁边的环境清单单独核验。


主机前端、ASG 及 Vulkan 原生合成使用安装工具支持的参数；Vulkan 原生合成的官方说明见[Android Emulator 版本说明](https://developer.android.com/studio/releases/emulator)。工具 36.5.11 属于官方 Stable 的补丁版，未把它描述为 Canary 或确定存在版本缺陷。
