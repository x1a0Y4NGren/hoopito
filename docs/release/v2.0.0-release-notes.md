# HoopTrace v2.0.0

发行日期：2026-10-09 · Android `2.0.0+4`

## 中文

HoopTrace 2.0 把开赛、现场记录、赛后总结与球员成长连成完整流程。核心功能继续离线可用，无账号、广告、追踪或个人数据上传。

- **更快开赛：** 比赛、历史、球员三个主入口保留浏览状态。可用临时姓名、已有档案或就地创建球员，复用最近对局配置并交换双方。目标分支持 **1～999**，点击数字即可手动输入；取消赛前设置不创建比赛，重复确认不重复开赛。
- **现场好记：** 统一横屏计分页保留 `+1 / +2 / +3 / 未命中`、球场优先和 10 秒补点。保存状态、上一步操作、失败重试与可跳过的三步提示更清楚；持久化撤回顺序保留。修复记分或重新进入计分页后运行时钟重复累计的问题。
- **赛后看得懂：** 终场确认比分与记录范围后进入赛果页，查看比分走势、关键时刻和记录完整度，再分享战报或打开完整复盘。再来一场只复用双方和规则，不复制事件、比分、时钟或完整度声明。
- **长期有积累：** 临时参赛者可关联到新建或已有档案，并保留当场姓名；同名不自动归并。成长图表、两场对局比较、7/30/90 天时间窗和对手筛选使用一致统计口径。
- **统计有依据：** FG% 与 FT% 分开计算；未明确声明完整出手的样本不显示可信命中率，零出手显示暂无数据。落点覆盖按已确认的运动战落点除以已记录运动战出手计算，落点分布仅表示已记录样本。
- **数据可恢复：** 替换与安全副本回退前保护当前数据，完整校验后才允许改变数据库；活动比赛期间禁止替换或回退。正常保留最近两份内部安全副本。完整 JSON 导出与导入共同使用 32 MiB、单表 100,000 行、总计 200,000 行上限，超限或损坏文件不会替换当前数据。
- **新球怪标识：** 采用 C「独眼球怪」和黑白橙配色，统一图标与启动画面。约一秒的静音 Q 弹跳跃包含上半部水波和局部收尾余波，支持平滑跳过、减少或关闭动画；慢初始化保持静态画面。

### 安装与数据兼容

本版使用新正式 Android 签名证书，**不能覆盖安装历史 v1 包**。新证书 SHA-256：

```text
2820ba06e898be1152d38536492282127e9fb0734a0863bb42db63f8a75611dd
```

若设备仍安装旧版且有需要保留的记录：先在旧版导出完整 JSON，确认应用之外已收到可读取的文件；再卸载旧版、安装新版并导入备份。卸载会删除应用私有数据库与内部安全副本。CSV 和战报图片不是恢复文件。

数据库仍为 **schema 3**，完整备份仍为 **JSON 格式 2**。支持格式 1/schema 2 与格式 2/schema 3 两种已有备份组合；不支持的旧格式或更高版本会明确拒绝，不静默清空本机数据。详见[升级与备份指南](v2.0.0-upgrade.md)。

### 平台与已知范围

Android 为本次发行平台；iOS 已有无签名编译验证，未提供正式 iOS 安装包。自动备份默认关闭，只写入明确授权的目录。自然 24 小时调度未完成实测，不能保证后台任务在准确 24 小时执行；已有受控后台及恢复验证不等于自然调度通过。

大字体与数字键盘同时使用时，目标分范围和错误提示的弹窗布局已修正。已有 API24／36 正式包核心流程和数据恢复验证保留真实来源；最终包及公开下载核验见[发行记录](v2.0.0-release-record.md)。API24 模拟器的旧系统文件选择器曾需要 D-pad 完成选择；部分 Vulkan 模拟器出现过渲染等待 ANR，硬件 OpenGL 环境已完成流程，但未证明该 Vulkan 根因消除，未完成实体设备验收。完整变更见[CHANGELOG](../../CHANGELOG.md)，数据流说明见[隐私声明](../../PRIVACY.md)。

## English

HoopTrace 2.0 connects quick setup, courtside recording, results, and player growth. Core features remain available offline, with no accounts, ads, tracking, or personal-data upload.

- **Start quickly:** Match, History, and Players tabs retain your browsing state. Use temporary names, existing profiles, or create a player during setup. Reuse recent participants and rules, swap sides, and tap the target score to enter any integer from **1 to 999**. Cancelling setup creates no match; repeated confirmation creates only one.
- **Record on court:** The shared landscape workspace keeps `+1 / +2 / +3 / Miss`, court-first input, and the 10-second location follow-up. Save status, the last action, retry feedback, and a skippable three-step guide make recording clearer. Undo follows persisted action order. The running clock no longer accumulates elapsed time again after scoring or reopening the page.
- **Understand the result:** Confirm the score and recording scope, then view the result summary, score progression, key moments, and recording completeness. Share a report or open the full replay. A rematch reuses only participants and rules, with fresh scores, events, clock, and coverage declaration.
- **Build a player history:** Link temporary participants to new or existing profiles while keeping their name from that match. Names alone never merge people. Growth charts, two-match comparisons, 7/30/90-day windows, and opponent filters share the same statistics.
- **Trust the scope:** Field-goal and free-throw percentages use separate denominators. Incomplete recording shows no trusted percentage; zero attempts shows no data. Location coverage is confirmed field-goal locations divided by recorded field-goal attempts. Location charts describe recorded samples.
- **Recover safely:** Replacement and safety-copy rollback protect the current state before changing the database. An active match blocks either operation. The latest two valid private safety copies are normally retained. JSON export and import share limits of 32 MiB, 100,000 rows per table, and 200,000 total rows. Invalid or oversized backups leave current data intact.
- **Meet the cyclops:** The approved cyclops basketball logo uses black, white, and orange across icons and the launch screen. Its roughly one-second, silent elastic bounce includes an upper-body wave and a brief final ripple, with smooth skip and reduced/disabled motion. Slow initialization holds the static logo.

### Installation and compatibility

This release uses a new production Android certificate, so **it cannot update the historical v1 APK in place**. Its SHA-256 fingerprint appears above.

If an old installation contains records you want to keep, export a complete JSON backup and confirm that a readable copy exists outside the app. Then uninstall the old package, install v2, and restore the JSON. Uninstalling removes the private database and internal safety copies. CSV and report images cannot restore your data.

The database remains **schema 3** and complete backups remain **JSON format 2**. Both format 1/schema 2 and format 2/schema 3 backups are supported. Unsupported legacy combinations and newer versions are rejected without silently clearing existing data. See the [upgrade and backup guide](v2.0.0-upgrade.md).

### Platform and verification scope

Android is the release platform. iOS has an unsigned build check but no formal installable release. Automatic backup is off by default and writes only to an explicitly authorized folder. A natural 24-hour scheduling observation has not been completed; background work is not guaranteed to execute at an exact 24-hour interval. Controlled worker and recovery checks do not establish natural scheduling success.

The target-score dialog now keeps the range and validation message readable with large text and the numeric keyboard. Earlier API24/36 core flows and recovery checks retain their actual package provenance; final-package and public-download verification are listed in the [release record](v2.0.0-release-record.md). The legacy API24 emulator file picker required D-pad input in one run. Some Vulkan emulator configurations experienced a renderer-wait ANR; hardware OpenGL flows passed, but that Vulkan cause has not been proven resolved and physical-device acceptance is incomplete. See the [changelog](../../CHANGELOG.md) and [privacy statement](../../PRIVACY.md) for details.
