# Hoopito · 球豆 v2.0.1

Android `2.0.1+5`，数据库 schema 3，JSON 格式 2。

## 中文

项目正式更名为 **球豆**，英文名称为 **Hoopito**。App 界面、系统安装名称、网站、当前文档与宣传素材统一新品牌，继续使用已批准的独眼球怪 Logo。核心记录、复盘和数据管理仍可离线使用。

**从 v2.0.0 升级：**保留原 Application ID 和 v2 正式签名，可直接覆盖安装；已有比赛、球员、规则、设置及私有安全副本继续读取。建议升级前将完整 JSON 保存到 App 外。

**备份兼容方向：**新版本可导入旧 HoopTrace 和新 Hoopito JSON，并识别两种名称的自动备份。新导出文件使用 `hoopito-` 前缀，JSON 的 `appName` 为 `Hoopito`；已发布的旧 App 不能导入这种新备份。CSV 和图片不能用于完整恢复。

**历史 v1：**v1 与 v2 正式证书不同，不能直接覆盖安装。请先导出并确认完整 JSON 已保存到 App 外，再卸载旧版、安装新版并恢复；卸载会删除应用私有数据。

旧发行 APK、tag、校验和及截图来源继续保留原名称。网站仍为受保护的预览，生产上线未包含在本次发布中。iOS 未提供正式安装包，商店及 F-Droid 渠道未发布。

## English

The app is now **Hoopito**, named **球豆** in Chinese. App screens, Android installation labels, the website, current documentation and promotional images use the new brand. The approved one-eyed basketball logo is retained. Scoring, replay and data management remain available offline.

**Updating from v2.0.0:** the application ID and official v2 signing certificate are unchanged. Install over the existing app to preserve matches, players, rules, settings and private safety copies. Save a complete JSON backup outside the app before updating.

**Backup compatibility is one-way:** this version imports both legacy HoopTrace and new Hoopito JSON, and recognizes both automatic-backup prefixes. New exports use the `hoopito-` prefix and `appName: Hoopito`. Published older apps cannot import these new backups. CSV and images are not complete recovery formats.

**Historical v1 installations:** v1 and v2 use different official certificates. Export and verify a complete JSON backup outside the app before uninstalling, installing this version and restoring it. Uninstallation removes private app data.

Historical APKs, tags, checksums and screenshot provenance keep their original names. The website remains a protected preview; production hosting is outside this release. No official iOS package, store release or F-Droid release is provided.
