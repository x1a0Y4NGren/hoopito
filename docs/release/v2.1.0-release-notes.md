# Hoopito · 球豆 v2.1.0

Android `2.1.0+6`，数据库 schema 4，JSON 格式 2。安装包、校验和与公开状态以对应 GitHub Release 为准。

## 中文

### 连续对局

- 赛前可选择“单场比赛”或“连续对局”。连续对局固定同一对球员，也支持临时姓名；交换红蓝方后仍正确累计各自胜场。
- 每场独立计分、计时、撤销和复盘。赛后可直接开始下一场，也可先调整规则、计时或红蓝位置；新一场从零开始，不继承比分、事件、计时进度或记录完整度确认。
- 胜场由已完赛或归档的比赛计算，平局单列，放弃不算胜负；纠分或删除比赛后会重新计算。组内每场只计入球员生涯一次，普通单场仍独立使用。
- 首页可继续未结束的对局，历史可查看整组并进入每场赛果与复盘。结束整组前须先完成或明确放弃当前比赛；没有其他未结束组或活动比赛时，可从历史重新打开，之后自行开始下一场。

### 计分与界面

赛前明确区分自由计分和目标计分。达到目标后保留真实比分，包括超出目标的得分；可补最后一球落点、确认结束、继续或撤销。选择继续后本场不再提醒目标分，计时到期仍然生效。结束并保存后显示胜者或平局，中英文文案与关键操作说明也作了整理。

### Android 应用内更新

“设置 → 软件更新”可手动检查、下载和安装。“启动时检查更新”默认开启，可随时关闭；没有新版或自动检查失败不会打扰计分。未结束的比赛会延后提醒，安装前须没有活动比赛，并由你在 Android 系统安装器中确认。下载可在后台继续，支持取消和重试；没有静默安装或强制更新。

**v2.0.1 不含更新器，需先手动安装一次 v2.1.0 或更高版本。** 更新检查优先使用官网的有效版本信息，官网不可用或信息无效时才尝试 GitHub。官网更新信息可能落后于 GitHub Release，因此 GitHub 发布新版后不保证立即出现应用内提醒；可直接从对应 Release 手动下载安装。

### 升级与备份

**v2.0.0／v2.0.1：**沿用 v2 正式签名和安装身份，可直接覆盖安装，保留已有比赛、球员、规则、设置和私有安全副本。升级前请将完整 JSON 备份保存并确认收到 App 外。旧比赛保持独立，不会自动编入连续对局。

本版将 schema 2／3 的本地数据库自动迁移至 **schema 4**，JSON 外层格式仍为 **2**，继续识别旧 HoopTrace 和新 Hoopito 备份。支持的完整 JSON 导入组合如下：

| JSON 格式 | 数据库 schema | 恢复内容 |
| --- | --- | --- |
| 1 | 2 | 旧版比赛及对应数据，无连续对局关系 |
| 2 | 3 | 比赛及对应数据，原比赛保持独立 |
| 2 | 4 | 同时包含连续对局及场次关联 |

**旧 App 无法导入本版的 schema 4 备份，也无法读取升级后的数据库，请勿降级后尝试继续使用该数据库。** CSV 和战报图片不能代替完整 JSON 备份。替换恢复仍会先保存并验证当前数据的安全副本，活动比赛期间不能替换。合并导入时，备份中的未结束整组转为已结束，未完成比赛按原规则转为放弃；之后可在条件满足时重新打开整组。

**历史 v1：**v1 与 v2 正式证书不同，不能直接覆盖安装。先导出并确认完整 JSON 已保存到 App 外，再卸载旧版、安装新版并恢复；卸载会删除应用私有数据。

计分、历史、复盘和数据管理继续离线可用。更新检查及下载会连接官网或 GitHub，不上传比赛、球员、设置或设备标识；分发服务会接收必要的连接信息，详见[隐私说明](../../PRIVACY.md)。本版面向 Android，未提供正式 iOS 安装包，也未发布商店或 F-Droid 渠道。

## English

### Continuous matches

- Choose Single match or Continuous matches before starting. A series keeps the same pair, including players entered with temporary names. Swapping red and blue preserves each player's identity and win count.
- Each game has its own score, clock, undo history and replay. Start the next game directly or change its rules, timer and colors first. A new game starts from zero without carrying over scores, events, clock progress or recording-completeness confirmations.
- Wins come from finished or archived games. Draws are listed separately; abandoned games do not count as wins or losses. Score corrections and deletions update the totals. Each game counts once toward player career statistics, and standalone matches remain independent.
- Continue an open series from Home, or open its games and replays from History. Finish or explicitly abandon the current game before closing a series. Reopen it from History when no other series or match is active, then start the next game when ready.

### Scoring and interface

Pregame now separates free scoring from target scoring. Reaching the target keeps the actual score, including points above the target. Add the last shot's location, confirm the finish, continue playing or undo the score. Continuing disables further target reminders for that game; the timer can still expire. The saved result shows the winner or a draw. English and Chinese text and key action explanations have also been refined.

### Android in-app updates

Settings → Software update lets you check, download and install manually. Check for updates at startup is on by default and can be turned off. Automatic checks stay quiet when no update is found or a check fails. Unfinished matches defer reminders. Installation requires no active match and your confirmation in the Android system installer. Downloads can continue in the background and can be canceled or retried. Updates are never forced or installed silently.

**v2.0.1 has no updater: install v2.1.0 or later manually once to get it.** Checks use valid website version information first and try GitHub only if that source fails or is invalid. The website feed may lag behind GitHub Releases, so a new GitHub release may not appear in the app immediately. You can download and install it directly from its Release page.

### Upgrading and backups

**From v2.0.0 or v2.0.1:** the official v2 signing certificate and application identity are retained. Install over the existing app to preserve matches, players, rules, settings and private safety copies. First save and verify a complete JSON backup outside the app. Existing matches remain separate and are not automatically grouped into a series.

Local schema 2 or 3 databases migrate automatically to **schema 4**. The JSON format remains **2**, and legacy HoopTrace and current Hoopito backups are recognized. Supported complete JSON imports are:

| JSON format | Database schema | Restored data |
| --- | --- | --- |
| 1 | 2 | Legacy matches and related data, without series links |
| 2 | 3 | Matches and related data; existing matches stay separate |
| 2 | 4 | Also includes series and game links |

**Older apps cannot import this version's schema 4 backups or read the upgraded database. Do not downgrade and reuse that database.** CSV files and replay images are not complete recovery formats. Replacement still saves and verifies a safety copy of current data first and is blocked during an active match. Merging a backup closes its open series and abandons unfinished matches under the existing import rules; a series can be reopened later when the conditions allow.

**Historical v1 installations:** v1 and v2 use different official certificates and cannot update in place. Export and verify a complete JSON backup outside the app, then uninstall the old app, install this version and restore. Uninstalling removes private app data.

Scoring, history, replay and data management remain available offline. Update checks and downloads connect to the website or GitHub without uploading matches, players, settings or device identifiers. Distribution services receive the connection information needed to serve requests; see the [privacy policy](../../PRIVACY.md). This version targets Android. No official iOS package, store release or F-Droid release is provided.
