## 中文候选发行说明

2.0 串起离线单挑的完整过程：快速开赛、放心记录、看懂结果，再把可靠数据留在球员历史中。

- 全新 C「独眼球怪」标识、平台与单色图标，以及静音的 Q 弹跳跃、上半部水波和局部余波启动动画，淘汰旧篮筐／轨迹标识。
- 比赛、历史、球员三个主入口保留各自页面状态；最近比赛直达赛后总结。
- 赛前支持临时名称、已有档案、内联新建球员、最近比赛配置、交换双方和规则摘要。复用配置只复制参与者与规则，不携带比分、事件或计时状态。
- 赛前目标分支持 1～999，可点数字直接输入；非法值保留输入并提示错误，取消不改规则，最近配置与再赛保留三位数设置。
- 横屏计分继续使用双方固定的 `+1 / +2 / +3 / 未命中`；增加保存状态、上一步操作、失败重试及可跳过的三步指引。
- 修复记分或重新进入后运行计时显示重复累计，正计时／倒计时继续保留原始时钟及到时停止状态。
- 结束时确认比分和是否记下每次出手。总结提供比分、关键回合、记录范围、复盘、报告分享、关联档案和再来一场。
- 球员列表主要打开生涯；成长、对手筛选和比较统一区分“已记录样本”与可信命中率。FG% 与 FT% 使用各自分母，不完整或零出手显示无数据。
- 替换恢复或回退前必须保存经回读校验的内部安全副本。活动比赛期间禁止替换；成功恢复后通常保留最近两份。
- 完整 JSON 导出与导入使用相同容量上限。球员统计 CSV 改为 13 列，分别给出 FG/FT 计数与命中率，并保留临时参与者身份。

核心仍可离线使用，无账号、广告、追踪或云同步；官方项目永久免费、开源。自动备份默认关闭，仅写入用户授权目录。详细数据边界见[升级与备份指南](v2.0.0-upgrade.md)。

## English candidate release notes

HoopTrace 2.0 connects the offline 1v1 journey: start quickly, record confidently, understand the result, and keep trustworthy player history.

- Set pregame targets from 1 to 999 by tapping the number. Invalid entries stay editable, cancelling preserves the current rule, and recent setups and rematches retain three-digit targets.
- A new cyclops basketball identity and platform/monochrome icons replace the previous mark. The silent entry adds an elastic hop, upper-body waves, and a short finishing ripple.
- Match, History, and Players retain their tab state; recent results open a result summary.
- Pregame supports temporary names, existing profiles, inline profile creation, recent setup, side swapping, and a rule summary. Reusing setup carries players and rules without scores, events, or clock state.
- The landscape workspace retains fixed `+1 / +2 / +3 / miss` controls on both sides, with clearer save state, the last action, retry feedback, and a skippable three-step guide.
- Running clock display counts elapsed time once after scoring or page re-entry, preserving count-up/countdown state and expiry handling.
- Finishing confirms both score and attempt coverage. The summary offers key moments, replay, report sharing, profile linking, and a rematch.
- Player rows open careers. Growth, opponent filters, and comparisons distinguish recorded samples from reliable percentages. FG% and FT% use separate denominators; incomplete or zero-attempt samples show no percentage.
- Replacement and rollback require a verified private safety copy. Active matches block replacement, and successful recovery normally retains the latest two copies.
- JSON export and import share the same capacity limits. Player-statistics CSV now has 13 columns with separate FG/FT evidence and distinct temporary participant identities.

Core features remain offline, account-free, ad-free, and tracker-free. The official project remains permanently free and open source. Automatic backup is off by default and writes only to a user-approved directory. See the [bilingual upgrade and backup guide](v2.0.0-upgrade.md).
