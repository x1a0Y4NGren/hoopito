## 行为与兼容

- 赛前高级设置中的目标分使用 1～999 共用编辑范围；1 时禁用减分，999 时禁用加分。中间数字的触控高度至少 48dp，可朗读目标分、当前值并直接激活。
- 输入框预填并全选当前值，自动聚焦数字键盘；确认与完成键使用同一校验。非法输入显示“请输入 1～999 的整数”，保留原文，不截断、不偷偷改值。
- 取消、系统返回、外部点击保留原目标；重复打开只有一个弹窗，重复提交／取消不会弹出下层赛前页。
- 确认仅更改本场赛前配置及规则摘要；开始时才分配比赛 ID。持久化规则快照、最近预填和交换再赛保持 100～999，达到目标仍显示原有非阻断终场提示。
- 默认规则与模板切换重置行为不变；既有正整数模板、历史和备份按原契约读取。schema 3、JSON 格式 2、版本 `2.0.0+4` 保持不变。
