# Hoopito · 球豆 C「独眼球怪」正式标识

当前品牌名称为 Hoopito · 球豆，继续使用已审核的 C 图形；名称与升级兼容规则见[品牌与兼容性](naming-and-compatibility.md)。下列生成记录、原始文件名和验收 SHA 保留当时 HoopTrace 项目的真实来源。

2026-10-04，用户确认：“C是我打算作为logo，制作成图标吧，原来的彻底淘汰了”。
据此将第一轮 C 概念正式制作为应用资源，不再保留旧篮筐／轨迹标识的运行时入口。

![正式应用图标](../../../assets/icons/hoopito-app-icon.png)

## 设计与来源

保留不规则篮球轮廓、朝右上的大眼、月牙眼神光、歪嘴笑与两条篮球纹路。
竞技橙 `#FF5A1F`、近黑 `#101112`、暖白 `#F4F3EF`；无文字、渐变、立体或背景场景。

使用内置 ImageGen 编辑已经审核的 C，仅完成透明背景及平面源图准备。
[原始透明输出](hooptrace-c-imagegen-source.png)保留在此目录，生产资源与单色版本的
确定性派生流程见[资源说明](../../../assets/icons/README.md)。
精确提示词、工具和文件 SHA-256 见[来源记录](source.json)。

## 淘汰范围

Android 传统／自适应／单色启动器、iOS 全部 AppIcon、两语言商店图标、
Android／iOS 原生启动画面和 Flutter 启动动画统一使用 C。
删除旧 `hooptrace-entry-hoop.png`、五档 `launch_hoop.png` 和 Flutter 中直接绘制
篮板、篮网、投篮轨迹的旧画笔。球场与功能性篮球导航图标保留其业务用途。

已有八张真实发行截图不包含旧标识，保留截图原始提交和拍摄记录。
此前 `94bb58e` APK 与验收是历史候选检查点，不含本次新图标；不得改标为新版本。

## 检查范围

检查透明源图黑色细节、单色负空间、32／48／96／192 px 显示，以及圆形、
圆角方形、squircle 裁切；更新五张启动动画 Golden 并检查跳过、关闭动画、
降低动画和进程内只播放一次的行为。原生实际检查与构建结果记录在
[本轮验收](verification.md)。

后续 Q 弹动效将同一透明源图映射到 48×48 网格，加入上半部水波与局部余波，
启动反馈改为静音、无震动。原图和平台图标保持不变，参数及后续验证见
[Q 弹启动动画](entry-motion.md)。上方五张 Golden 与反馈检查描述保留首次标识替换的历史范围。
