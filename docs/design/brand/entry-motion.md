## 动作参数

原生与 Flutter 共用 288dp 画布、0.78 基础缩放。标准动作共 1000ms：

| 时间（ms） | 姿态 |
| --- | --- |
| 0–60 | 原图静止，衔接原生启动画面 |
| 60–150 | 下沉蓄力，纵向压缩 8% |
| 150–330 | 跃起 12dp，纵向伸展 6% |
| 330–480 | 落地压缩 9% |
| 480–620 | 回弹 3dp，恢复身体比例 |
| 620–760 | 上侧局部余波向右滚动，最大位移 2dp |
| 760–860 | 原图静止收势 |
| 860–1000 | 淡出到应用页面 |

跳跃期间，上半部两次衰减水波最大位移 3dp，向身体中部和眼睛、嘴部保护区平滑减弱。收尾余波作用于上侧约五分之一宽度，起止形变归零。48×48 纹理网格复用正式透明 PNG；不修改品牌源图。

## 启动契约

Android 初始 Surface 创建／resize 完成后开始图像与偏好准备：图像仍最多等待 100ms，并用单调时钟拒绝迟到结果；偏好仍最多等待 80ms。先提交匹配的静止首帧，再等待原生启动图移除回执，随后开始动作；API31+ 取消系统退出淡出，API24–30 使用首次 Flutter 显示回执。Surface 与展示等待各有 2s 的 Dart 超时，展示不可用时降级；这不对阻塞的原生线程实施硬取消。

页面尚未准备好时在原图静止姿态等待，超过 2 秒显示双语提示。错误和旧数据库保护页及时显示。点击最多 120ms 归零并跳过；减少动画仅淡出，关闭动画直接显示启动内容；同一进程不重复播放。迟到回执不重播，数据库初始化顺序、图像所有权和比赛反馈设置保持原有行为。
